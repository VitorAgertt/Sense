# Lista de Comandos Administrativos

## Administração (Nível 1)
> **/flash** - Ativa ou desativa a super velocidade (corrida rápida). \
> **/item** - Adiciona um item para você mesmo. \
> **/item2** - Adiciona um item para um jogador específico (via menu de ID). \
> **/itemall** - Adiciona um item para todos os jogadores online. \
> **/delete** - Deleta um personagem da base de dados (requer ID). \
> **/ban** - Abre um menu para banir um jogador (requer ID, motivo e tempo). \
> **/tuning** - Aplica melhorias (tuning) ao veículo atual. \
> **/addgem** - Adiciona "gemas" (moeda premium) a um jogador (via menu). \
> **/remgem** - Remove "gemas" (moeda premium) de um jogador (via menu). \
> **/addbank** - Adiciona dinheiro ao banco de um jogador (via menu). \
> **/rembank** - Remove dinheiro do banco de um jogador (via menu). \
> **/addcar** - Adiciona um veículo específico à garagem de um jogador. \
> **/remcar** - Remove um veículo específico da garagem de um jogador. \
> **/addback** - Aumenta o peso máximo da mochila de um jogador. \
> **/remback** - Reduz o peso máximo da mochila de um jogador. \
> **/kickall** - Desconecta todos os jogadores do servidor (usado para reinícios). \
> **/save** - Força o salvamento dos dados do servidor (provavelmente inventários/posições). \
> **/spectate** - Entra no modo espectador em um jogador (requer ID). \
> **/quake** / **/terremoto** - Ativa ou desativa o evento de terremoto (muda o clima para "THUNDER" e ativa o blackout). \
> **/humane** - Envia um anúncio global para todos os jogadores (via menu). \
> **/ene** - Ativa o modo "Energetic" (provavelmente relacionado à estamina ou velocidade). \
> **/pon** - (Função não encontrada no arquivo). \
> **/godmode** - Ativa ou desativa o modo Deus (invencibilidade) para você mesmo. \
> **/ney** - Aplica "ragdoll" (derruba) em um jogador (requer ID). \
> **/soco** - Ativa o "super soco" (soco forte) para você mesmo. \
> **/desbugar** - Teleporta o jogador para a localização de spawn (para sair de locais presos). \
> **/clearallobj** - Limpa todos os objetos "prop" spawnados no mapa (baseado na função `ClearObjs` do arquivo).

## Moderação (Nível 2)
> **/clearinv** - Limpa completamente o inventário de um jogador (requer ID). \
> **/resetskin** - Reseta a aparência (skin) de um jogador para o modelo padrão (MP Male/Female). \
> **/kick** - Desconecta (kicka) um jogador do servidor (requer ID e motivo via menu). \
> **/unban** - Remove o banimento de um jogador (requer ID). \
> **/timeset** - Define o tempo (hora, minutos) e o clima do servidor. \
> **/blackout** - Ativa ou desativa o "blackout" (apaga todas as luzes do mapa). \
> **/group** - Define o grupo (permissão) e o nível de um jogador. \
> **/ungroup** - Remove um jogador de um grupo (permissão). \
> **/fix** - Repara o veículo em que o administrador está. \
> **/limparea** - Limpa a área próxima ao administrador (provavelmente veículos e peds). \
> **/playersconnected** - Lista todos os jogadores conectados no momento. \
> **/wl** - Altera o status da whitelist de um jogador (via menu de ID e status 0 ou 1). \
> **/unwl** - Remove a whitelist de um jogador (define como inativa). \
> **/rename** - Abre um menu para renomear o personagem de um jogador (requer ID). \
> **/skin** - Abre um menu para trocar a skin (modelo) de um jogador (requer ID e nome da skin). \
> **/status2** - Mostra a contagem de jogadores em serviços (Polícia, Paramédico, etc.). \
> **/respiracao** - Ativa ou desativa um efeito de respiração (provavelmente fôlego infinito).

---
## Suporte (Nível 3)
> **/ugroups** - Verifica todos os grupos (permissões) que um jogador específico possui (requer ID). \
> **/god** - Revive, cura e restaura os status (fome/sede) de um jogador (ID) ou de si mesmo. \
> **/nc** - Ativa ou desativa o "NoClip" (modo fantasma, permite voar e atravessar objetos). \
> **/cds** - Copia as coordenadas exatas (X, Y, Z e Heading) do administrador. \
> **/tpcds** - Teleporta o administrador para coordenadas específicas (via menu). \
> **/tptome** - Teleporta um jogador (ID) até a sua localização atual. \
> **/tpto** - Teleporta você até a localização de um jogador (ID). \
> **/dm** - Envia uma mensagem direta (DM) para um jogador (requer ID e mensagem via menu). \
> **/tpway** - Teleporta o administrador para o marcador (waypoint) definido no mapa. \
> **/hash** - Obtém o hash (ID do modelo) do veículo ou objeto que você está olhando. \
> **/players** - Lista todos os jogadores conectados no momento. \
> **/usource** - Obtém o Passaporte (ID) de um jogador (requer o "source" ID). \
> **/passaporte** - Mostra informações detalhadas de um jogador (Nome, Source, Celular, Banco, etc.). \
> **/debug** - Ativa ou desativa informações de debug na tela.

---
### Uso geral
> **/staff** - Entra ou sai do modo de serviço administrativo.
